# TOOLS.md — Local Notes

Skills define _how_ tools work. This file is for _your_ environment-specific specifics.

## What goes here
- SSH hosts and aliases
- Device/room/speaker names
- Preferred TTS voices
- Anything unique to this setup

## Examples
```markdown
### SSH
- prod → user@host (deploy target)

### Voices
- default → "calm narrator"
```

> Do not put secrets here. Credentials live in `credentials/` and are referenced, never inlined.
